# getMyTest
## Avvio

**Windows:** fai doppio clic su `apri-verifica.cmd`, oppure esegui da PowerShell o dal Prompt dei comandi:

```powershell
.\apri-verifica.cmd
```

**Linux e macOS:** dalla cartella del progetto esegui:

```bash
sh ./apri-verifica.sh
```

Lo script apre `apri-verifica.html` nel browser predefinito. Puoi aprire il file HTML anche direttamente con un doppio clic.
